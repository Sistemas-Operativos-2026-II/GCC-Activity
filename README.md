# GCC Practice Files

This repository contains the C source files used for the GCC practice activity.

## Files

- `01_hello.c` — Basic C program.
- `02_warning.c` — Program used to explore compiler warnings.
- `03_error.c` — Program used to explore compilation errors.
- `04_threads.c` — Basic program using POSIX threads.
- `05_diagnosis.c` — Program used for compilation and debugging practice.

## Usage

Follow the instructions provided in the activity guide.

Some files may intentionally contain errors or warnings. Do not assume that every program is expected to compile successfully without modifications.
